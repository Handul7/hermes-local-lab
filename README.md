# Hermes Local Lab

Mac mini 32GB를 중심으로 Hermes Agent, 로컬 AI 모델, 받아쓰기, 원격 접속과 홈서버 활용을 비교하는 한국어 가이드입니다.

## 웹사이트

GitHub Pages: https://handul7.github.io/hermes-local-lab/

- 용도에 맞는 설치 후보 선택과 개인 설치 목록
- 모델·받아쓰기 도구 비교 및 공식 설치 링크
- 국내외 실제 활용 사례와 출처
- 기기 준비, 원격 운영, 저장장치 및 용어집

## 개인정보와 한계

설치 목록과 진행 상태는 이용 중인 브라우저의 로컬 저장소에만 저장됩니다. 계정 동기화나 실제 프로그램 설치를 수행하지 않습니다. 로컬 파일로 사용하던 선택은 공개 사이트로 자동 이전되지 않습니다.

연결된 서비스는 각 서비스의 정책을 따릅니다. 브랜드 로고의 권리는 각 권리자에게 있습니다. 일부 브랜드 아이콘은 [Lobe Icons](https://github.com/lobehub/lobe-icons)를 참고합니다. Apple 또는 도구 개발사의 공식 사이트가 아닌 독립적인 개인 가이드입니다.

모델·가격·지원 환경은 변할 수 있으므로 설치 전 공식 출처를 확인하세요. 기기 성능과 한국어 정확도를 직접 실측한 벤치마크가 아닙니다.

## 구성

별도 빌드나 서버가 필요 없는 HTML·CSS·JavaScript 사이트입니다. `index.html`이 시작 페이지이며, GitHub Pages는 `main` 브랜치의 루트에서 배포합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다.
